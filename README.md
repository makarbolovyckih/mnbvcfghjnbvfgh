# Player
SwiftUI music player. Build with the included GitHub Actions workflow (Actions tab > Build IPA > download the `Player-ipa` artifact), then sideload Player.ipa with Sideloadly.

Widgets: long-press the Home Screen > + > Player > Now Playing (small or medium). The widget needs the shared app group `group.com.example.player` to show the current song; the buttons are App Intents that run inside the app.
